## building

- **The fit engine.** Paste a job spec on the homepage, get an honest read
  on whether I fit the role, cited against real shipped work. It will say
  no when the answer is no; that is the point of it.
- **Agent-owned /now.** A scheduled agent reads my actual activity
  (commits across repos, the argus morning briefs) and rewrites the now
  page weekly. The byline and commit author change so you can tell it
  wasn't me.
- **The cost counter.** The footer will show what this site spent on
  inference today, in pounds. Nobody publishes this number. I think that
  is strange.

## exploring

- **An MCP server for this site.** So your agent can interrogate my work
  directly instead of scraping HTML: `get_projects`, `get_now`,
  `get_fit(job_spec)`.
- **A real domain.** The GitHub Pages URL does the job while the content
  earns something better.
